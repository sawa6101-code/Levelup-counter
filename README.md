# Levelup-counter

キャラクターの現在レベルとレアリティ（R / SR / SSR）から、最大Lvまでに必要な赤リンゴ・虹リンゴを自動計算するPWAです。

## 対応レアリティ

| レアリティ | 最大Lv | 虹リンゴ総数 |
|---|---:|---:|
| R | 150 | 450 |
| SR | 175 | 1650 |
| SSR | 200 | 2880 |

## 計算仕様

- 赤リンゴ：提示された経験の果実データの累計必要数を使用。
- 虹リンゴ：現在Lvより上の限界突破地点に必要な数だけ合計。
- レベル入力は選択したレアリティの最大Lvを上限とします。
- 入力状態はブラウザのlocalStorageに保存します。
- Service Workerによるオフライン利用に対応しています。

## データ

経験の果実（赤リンゴ）と限界突破の果実（虹リンゴ）の数値は、提供されたデータシートを基準に実装しています。
